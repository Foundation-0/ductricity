# ductricity

A duct whose wall is the same surface that shakes the flow and extracts from it.

A duct is a tunnel that guides a fluid, such as air or water. In a normal duct the wall only guides. The energy leaves with the fluid.

This project designs a duct where the wall does two jobs at once. It shapes the flow into drafts and eddies, and it takes energy out of the flow it shaped.
